# Code of Conduct

## Our standard

Participation in this project is expected to be respectful, constructive, and focused on improving the work. People of different experience levels should be able to ask questions, report defects, and discuss technical decisions without being harassed or demeaned.

## Expected behavior

- Be considerate and professional.
- Critique code, evidence, assumptions, and methods rather than attacking people.
- Explain disagreements with relevant technical reasoning.
- Accept good-faith corrections.
- Respect privacy, dataset licenses, and attribution requirements.
- Keep issues and reviews focused on actionable project matters.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, intimidation, deliberate disruption, and publishing private or confidential information are not acceptable. Sharing credentials or restricted passenger data is prohibited.

## Reporting

Report conduct concerns privately to the project maintainer, Brajesh Kumar, through the private contact route available from the maintainer's GitHub profile. Include a concise description and relevant context. Do not post sensitive details in a public issue.

Reports will be reviewed as fairly and confidentially as possible. Maintainers may edit, remove, or reject contributions and may restrict participation when necessary to protect the community.

## Scope

This code applies to project spaces, issue discussions, pull requests, and other spaces where a person represents or participates in this project.
