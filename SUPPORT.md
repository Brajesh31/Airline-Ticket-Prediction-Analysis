## Before asking for help

Try to reproduce the problem from a clean kernel. Include:

- Operating system and Python version.
- Relevant dependency versions.
- Notebook cell number and sanitized traceback.
- Expected behavior and actual behavior.
- The shape and column names of the dataset, without sharing sensitive rows.
- Dataset version or provenance when relevant.
- The validation split and command used, if the question concerns model metrics.

## Where to ask

Use GitHub Issues for reproducible bugs, feature proposals, and documentation corrections. Select the appropriate issue template. For suspected security problems or exposed private data, follow [SECURITY.md](SECURITY.md) instead of filing a public issue.

## Support boundaries

This is an educational analysis, not a live flight search or booking service. Support cannot guarantee fare estimates, airline availability, or the legality of a third-party dataset. Do not upload passenger records, credentials, booking references, or unlicensed data when asking for help.
