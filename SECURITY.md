# Security Policy

This repository contains an offline analysis notebook, not a production fare service.

Report vulnerabilities privately to Brajesh Kumar (`brajesh31`) through the private contact route on the GitHub profile. Include affected paths, impact and sanitized reproduction steps. Do not publish credentials, exploit details or private dataset samples in public issues.

Never commit API keys, passwords, passenger names, contact details, PNRs, payment data or restricted datasets. Inspect notebook outputs and rotate any exposed credentials. Review notebooks from untrusted sources before executing them because notebook cells can run arbitrary code with the user's permissions.

There are no formal versioned releases or supported production environments yet.
